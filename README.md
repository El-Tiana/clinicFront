# ClinicFront

Application web de gestion médicale développée en Angular, dans le cadre d'un projet scolaire (solo).

## Fonctionnalités

- Gestion des patients (fiches patients)
- Gestion des ordonnances et des médicaments
- Suivi des maladies et symptômes
- Authentification et gestion des rôles (médecin / patient)
- Inscription des médecins

## Stack

- **Front-end :** Angular 10, Bootstrap, TypeScript
- **Back-end :** API REST consommée par l'application (hébergée séparément)

## Lancer le projet

\`\`\`bash
npm install
ng serve
\`\`\`
Application disponible sur `http://localhost:4200`
